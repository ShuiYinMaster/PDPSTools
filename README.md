# PDPSTools

面向 Windows 的 PDPS / CATIA 桌面工具箱，集中处理项目目录、PSZ 工程、焊点与螺柱点位、几何中心和 Excel 数据。

## 下载与运行

当前版本：**v2.3.0（2026-10-17）**。

- [下载 Windows x64 EXE](https://github.com/ShuiYinMaster/PDPSTools/releases/download/v2.3.0/PDPSTools-v2.3.0-windows-x64.exe)
- [查看发行版说明](https://github.com/ShuiYinMaster/PDPSTools/releases/tag/v2.3.0)
- [完整更新日志](CHANGELOG.md)

将 EXE 放在可写的文件夹中，双击即可运行，无需另外安装 Python。CATIA 功能需要已安装并启动 CATIA V5。

升级时先关闭旧版，将新 EXE 放在原目录中，保留原有配置文件，即可继续使用已有项目数据。

## 功能

| 模块 | 功能 |
| --- | --- |
| 项目路径管理 | 添加目录、后台扫描、项目筛选、预览、元数据维护与启动项目 |

| CATIA 点位 | 焊点 / BiW 提取、螺柱装配原点读取与创建、CSV / Excel 导入 |
| 点位检测与导出 | 三维距离去重、跨来源比对、导出全部 / 保留 / 重复点 |
| 几何中心 | 读取 3DXML、扫描 CATIA 几何体与图形集、生成中心点 |
| 插枪与 Excel | CATIA 焊枪放置及 Excel 图形工具 |

## 首次使用

1. 没有项目数据时，项目页会显示目录引导，点击“添加项目目录”。
2. 选择包含 `.psz` 文件的目录，程序会自动扫描子目录；也可以将文件夹拖入窗口。
3. 在列表中选择项目，查看详情或启动项目；点击“保存数据”，下次启动时继续使用。

已添加目录但没有项目数据时，可以从引导页重新扫描。已有项目数据时，引导自动隐藏。

## CATIA 点位工作流

### 螺柱点位

在 CATIA 中激活 CATProduct 后，打开“Catia工具箱”的“螺柱点位”区域。

默认关键字 `Q114` 可同时匹配名称或零件号中包含 `Q114`、`FQ114` 的实例。不区分大小写，也支持逗号分隔多个关键字，例如 `Q114,FQ114`；同一实例不会重复计数。

先点击“读取螺柱点位”，核对实例名称、零件号、装配路径和毫米坐标，再点击“确认并创建原点”。修改关键字后需要重新读取。跨子装配的同名实例按路径区分，生成点的名称保持唯一。

点位表示组件局部原点在活动根装配坐标系中的位置。创建前会重新核对装配数据；已有同名输出 CATPart 时停止重复创建，创建失败时尝试移除本次新建组件。

现场只读验证成功读取 32 个实例：其中 `FQ114` 6 个，其余 `Q114` 26 个，原点坐标与 CATIA 返回值一致。详情见 [螺柱点位获取验证](docs/CATIA_STUD_VALIDATION.md)。

### 导入、去重与导出

CSV / Excel 导入支持 `X/Y/Z`、`x_mm/y_mm/z_mm` 或 `center_x_mm/center_y_mm/center_z_mm` 列。`unit` 列可声明 `mm`、`cm`、`m`、`in`，坐标统一转为 mm；未声明时按 mm 处理。未提供坐标系时记录为 `unspecified`。

焊点和几何中心按三维距离标记重复点，默认阈值 5 mm。可调整阈值，或勾选“焊点仅看重复”筛选焊点表；“导入时追加”可检测跨来源重复点。检测保留原始记录，导出可选择全部、保留或重复点，并附来源、坐标系、原始单位、阈值、主点和距离。

工具箱按钮随窗口宽度换行，表格列宽自动适配。长名称和路径显示省略号，悬停可查看完整值。

### 3DXML 焊点候选识别

“扫描3DXML”默认按装配关联查找小型网格符号，`XWS` 是可修改、可关闭的零件名称线索。支持自动、仅名称范围、仅几何特征，以及旧版包络中心四种策略；最大符号包络半径可调整，默认 20 mm。坐标按各实例的装配变换转换为根装配毫米坐标。

当前新焊点路径验证了 CATIA `V5_CFV3` 的节点/网格结构，并使用重复小网格族及可解码的立方体顶点特征。压缩网格未完全解码时显示“小型符号候选”，悬停可查看形状假设和证据。按业务规则，已识别正方体归为 3T，圆锥归为 4T，球形及无法识别形状的候选默认 2T；默认 2T 不代表已验证球面。不支持的编码会给出诊断，可切换旧版包络中心检查。匿名化的验证结论见 [CATIA 几何体生成说明](docs/CATIA_WELD_GEOMETRY.md)，仓库不包含现场模型或点位坐标数据。

### 交互点位投影

工具箱以“焊点数据 / 3DXML与几何中心 / 螺柱点位”页签组织数据，右侧常驻当前列表的投影图。分隔条可拖动调整比例，窄窗口改为上下排列；窄布局默认收起识别参数和点位详情，可点击“识别参数”或“详情”展开。公共区域提供去重阈值、重复点筛选、详细列和导出范围。

图表支持 XZ、XY、YZ 三种毫米等比例投影，以及可旋转的 3D 正交点位视图（显示点位，不加载整车 CAD 曲面）。点击点位会选中并滚动到对应列表行，列表选择也会高亮图中点位；重叠或遮挡点可以连续点击切换。滚轮以鼠标位置为中心缩放，二维拖动平移；3D 左键拖动旋转，Shift+拖动或中键拖动平移。双击恢复默认视角，“适合窗口”适配当前视角，“保存图片”导出当前 PNG 视图。

所有数据页和视图统一显示：2T 蓝色球体、3T 橙色正方体、4T 绿色圆锥；二维投影保留同样的立体符号。已识别的正方体、圆锥、球形优先对应 3T、4T、2T；无已识别几何的 CSV 等数据沿用 Type / WeldLayers / LayerCount 中明确一致的层数，其余默认 2T，不设“未知层数”分类。形状假设不视为识别结果。该规则同步用于导入、几何传入、导出和统计。红色虚线环标记重复点，黄色大环与十字标记选中点；未选点淡化，列表用深蓝底、白色粗体和金色边框突出选中行，焦点在图表时仍保留高亮。

图例实时显示各层数有效点数量；详情区域的“分类统计”页分别列出各类的全量总数、当前列表行数、有效坐标点数和选中点数，随筛选、选中和数据页切换更新。“点位详情”页显示选中点层数、名称、坐标及识别证据。

默认表格聚焦名称、XYZ、类型和重复状态；“详细列”展开完整字段。坐标显示三位小数，悬停和点位详情显示完整值，生成、传入和导出继续使用原始坐标精度。图表省略无效坐标并显示数量；各页数据独立，切换页签时图表跟随切换。

### 点位几何体生成与制造特征导出

“生成点球/几何体”按统一层数规则创建 2T 球面、3T 正方体实体、4T 圆锥实体，并使用蓝、橙、绿区分。3DXML / 几何中心页也可直接点击“生成点位几何体”，无需先传入焊点表；“生成重心点”仍仅生成中心点。

尺寸参数默认 3 mm，分别作为球半径、正方体半边长、圆锥底面半径；正方体边长与圆锥高度均为参数的两倍。球心、正方体中心、圆锥体积重心均位于点位 XYZ。圆锥沿目标 Part 的 Z 轴，辅助点、草图及支撑平面隐藏。

生成目标根据实际 COM 能力判断，不因窗口名为 `.3dxml` 就禁止操作。活动文档提供可编辑的 Product 时，在其下新建独立 CATPart（包括 CATIA 暴露为 Product 的 3DXML）；活动 CATPart 内则创建本批次专属几何集/实体。若 CATIA 实际拒绝创建，显示真实错误，不另开空装配，不自动启动新的 CATIA。Product 根坐标转换到新组件局部坐标；CATPart 使用其局部坐标。开始前确认目标，后台执行前再次校验活动文档；无效坐标不会默认填零，Update 失败不计作成功。失败或取消删除本批次新建的组件/特征，清理异常会列出待检查的名称。CATIA 可能暂时保留已移除组件的无窗口文档缓存，但不保留其装配实例，也不保存到磁盘。

生成结果不会自动保存或覆盖源 3DXML。请在确认后自行另存 CATPart / CATProduct。焊点页原“导出点位”按钮现名为“导出制造特征（mfg）”，仍保留原有 CSV / Excel 点位报告格式与导出范围，没有将文件后缀改为 `.mfg`。

## 配置与数据

配置保存在 EXE 所在目录：`pdps_master_config.json`（项目数据）、`paths_config.json`（搜索目录）、`recent_projects.json`（最近项目）和 `pdps_ui_settings.json`（界面设置）。

PSZ 回写会先生成临时包、校验 XML 与 ZIP，再原子替换，并保留独立备份。程序关闭时会协调正在运行的后台任务。

## 源码运行与打包

维护基准为 **Python 3.13.3 / Windows x64**，直接依赖版本已固定。运行依赖和构建依赖分别位于 `requirements.txt`、`requirements-build.txt`。

```powershell
python -m pip install -r requirements.txt
python PDPSManagerApp.py
```

打包：

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --clean PDPSTools.spec
```

默认生成 `dist/PDPSTools.exe`，图标等资源随 EXE 打包。构建时建议使用独立输出目录；已有 `dist/` 或 `release/` 可能包含用户配置与导出数据。

回归测试：

```powershell
python -B -m unittest discover -s tests -v
```

Windows CI 会运行正式回归测试、隔离打包并执行 EXE 启动检查。当前源码通过 82 项本地回归测试；2026-10-17 在实际打开的 3DXML 外层 Product 中成功生成 108 个球体和 20 个正方体，抽检中心坐标通过，原文件未保存覆盖；圆锥在临时未保存 CATPart 中通过实体体积、重心坐标检查，另验证了取消后装配实例清理。不同 CATIA 版本和许可仍需现场验收。
