# 螺柱点位获取验证

日期：2026-10-14。

验证对象：用户提供的现场 CATProduct 装配（工程名称已匿名化）。

## 现场发现与修复

当前装配包含 32 个名称或零件号带 `Q114` 的实例。原有动态 COM `Position.GetComponents` 调用没有正确接收输出数组，导致有效实例被判为位置无效。现在保留原有调用方式，并在读取无效时通过 pycatia 的 CATIA 数组桥接读取；返回的旋转轴必须是有限、单位长度且相互正交，读取失败不会用零坐标替代。

支持逗号、分号及中文分隔符输入多个关键字。单独输入 `Q114` 已包含 `FQ114`，多个关键字命中同一实例只返回一条记录。跨子装配的同名实例按装配路径区分，生成点名称保持唯一。只读取匹配实例及其祖先的位置，避免无关组件的位置问题阻断整个提取过程。

点位含义是组件局部原点变换到活动装配根坐标系后的坐标，单位为 mm。此项验证没有核对原点与螺柱几何端面或安装面的对应关系。

## 只读验证结果

| 项目 | 结果 |
| --- | --- |
| 输入 `Q114` | 32 个实例 |
| 输入 `Q114,FQ114` | 同样 32 个实例，无重复计数 |
| 输入 `FQ114` | 6 个实例 |
| 其余 `Q114` 实例 | 26 个 |
| 与 CATIA 原生位置数组的原点坐标最大差值 | 0 mm |
| 生成点的计划名称 | 32 个名称均唯一 |
| 提取前后活动装配组件数量 | 一致 |

本次现场验证只读取装配；点的实际创建与失败回滚使用模拟 COM 回归验证。覆盖多关键字、同名实例、旋转叠加、无关组件位置异常、兼容数组读取、预览变化和创建回滚。
