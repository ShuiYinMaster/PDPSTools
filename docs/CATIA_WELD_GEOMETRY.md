# CATIA / 3DXML 点位几何体生成

## 支持与工作流

CATIA 有时把 3DXML 窗口暴露为常规 ProductDocument。生成逻辑检查实际 Part / Product COM 能力，不再仅凭 `.3dxml` 后缀拒绝操作。可编辑 Product 下创建本批次独立 CATPart；活动 CATPart 中创建独立几何集与实体。若 CATIA 实际拒绝操作，报告原始 API 错误，不另开装配、不启动新实例，也不覆盖源文件。

焊点页使用“生成点球/几何体”；几何中心页可直接使用“生成点位几何体”，无需先转入焊点表。“生成重心点”仍只生成中心点。

## 分类与尺寸

- 2T：蓝色整球面，半径为尺寸参数。
- 3T：橙色正方体实体，边长为尺寸参数的两倍。
- 4T：绿色圆锥实体，底面半径为尺寸参数，高度为尺寸参数的两倍。

尺寸默认 3 mm；球心、正方体中心、圆锥体积重心与输入 XYZ 一致。圆锥沿目标 Part Z 轴。辅助中心点、草图及支撑面隐藏。几何分类与 GUI 共用规则：识别到的正方体、圆锥、球形优先对应 3T、4T、2T；无已识别几何时保留明确一致的层数，其余默认 2T。

Product 输入坐标使用根装配坐标系，并转换为新组件局部坐标；活动 CATPart 使用局部坐标。草图使用通过目标坐标的专用支撑面，避免仅修改草图原点时法向坐标被 CATIA 投影到原始基准面。

## 事务与安全

开始前验证坐标、单位和尺寸；后台执行前再次校验活动文档。每个符号单独创建和 Update，失败不计为成功。取消或失败时移除本批次新组件 / 特征，保留已有几何；清理失败会显示待检查名称。关闭 / Esc 不会遗留后台线程继续生成。

不自动保存或覆盖源 3DXML；确认结果后由用户另存 CATPart / CATProduct。CATIA 可能保留已移除组件的无窗口文档缓存，不能以 Documents.Count 不变判断清理结果，应核对装配实例及原组件名单。

## 匿名验证记录（2026-10-17）

- 四份 3DXML 样本共提取 455 个候选，其中 57 个正方体通过顶点几何验证。启用与关闭 XWS 名称线索时，本组样本结果一致；这不代表所有 3DXML 均可无名称识别。
- 在当前 3DXML 外层 Product 的样本中生成 128 个符号：108 个整球面、20 个独立正方体；根子件数量由 21 增至 22，球心 / 正方体重心抽检相对输入误差小于 0.00001 mm。未保存覆盖源文件。
- 临时 CATPart 中以尺寸 3 mm 验证三类原生几何体：正方体体积 216 mm³，圆锥体积约 56.5486678 mm³，球心 / 实体重心与指定测试坐标一致；验证零件未保存。
- 真实 Product 中取消单独测试批次后，原装配组件名单保持不变。实际失败注入使用模拟 COM 测试，不将其描述为所有 CATIA 错误条件下的现场保证。
- 82 项回归测试覆盖候选提取、Qt 双向选中、层数规则、单位及坐标、生成入口、文档切换、取消和回滚。
