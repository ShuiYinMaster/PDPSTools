# PDPSTools v2.2.0

本次更新完善首次使用和 CATIA 点位流程，修复螺柱坐标读取、工具箱横向溢出及 PSZ 回写与后台任务稳定性问题。

## 主要更新

- **首次使用引导**：无项目数据时可直接添加项目目录，选中后自动扫描子目录。
- **螺柱点位**：修复 COM 位置数组读取失败；默认 `Q114` 同时匹配 `FQ114`，支持多关键字与同名实例，预览显示装配路径和毫米坐标。
- **界面适配**：操作按钮随窗口宽度换行，表格列宽自动适配，长名称和路径悬停查看完整内容。
- **点位导入与导出**：支持 mm/cm/m/in 单位、追加导入、跨来源重复检测，以及全部/保留/重复点报告。
- **PSZ 稳定性**：区分 PS/EMS 对象，按条目限定删除；临时包校验后原子回写，独立备份并检查源文件变化。
- **维护与交付**：后台任务退出协调、扫描缓存失效与错误重试、纯函数服务拆分、依赖版本固定、Windows CI 测试与打包检查。

## 使用与升级

下载 `PDPSTools-v2.2.0-windows-x64.exe`，放在可写目录后双击运行。无需另装 Python；CATIA 功能需要已经安装并启动 CATIA V5。

升级时关闭旧版，将新 EXE 放在原目录，保留 `pdps_master_config.json`、`paths_config.json`、`recent_projects.json` 和 `pdps_ui_settings.json`。

螺柱点位先读取、核对，再确认创建；点位表示组件原点在活动根装配中的位置，单位 mm。
