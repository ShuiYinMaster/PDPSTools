# PDPSTools v2.3.0

本次更新加入 3DXML 焊点候选识别、交互投影与三维视图，并支持在可编辑的 3DXML 外层 Product 中按板层数生成点位几何体。

## 主要更新

- **3DXML 提取**：小型网格族与正方体顶点特征，装配变换到根坐标；XWS 是可修改、可关闭的名称线索，提供多种提取策略。
- **点位可视化**：XZ / XY / YZ 投影、可旋转 3D 点位视图、列表双向选中、重叠点切换、缩放平移及 PNG 导出。
- **分类统计**：2T 蓝色球体、3T 橙色正方体、4T 绿色圆锥，各页统一统计总数、当前列表、有效坐标和选中数量；未识别形状默认 2T。
- **CATIA 生成**：按实际 Product 能力新建独立 CATPart，不再因窗口名为 3DXML 禁用；2T 整球面、3T 正方体实体、4T 圆锥实体，支持几何页直接生成。
- **安全与定位**：修复草图支撑面导致的偏位，转换组件坐标，验证数据与活动文档，失败 / 取消清理本批次，强化列表选中显示。
- **导出名称**：“导出点位”现名为“导出制造特征（mfg）”，仍为 CSV / Excel 点位报告，保留去重阈值及导出范围设置。

## 使用与升级

下载 `PDPSTools-v2.3.0-windows-x64.exe`，放入可写文件夹双击运行，无需另装 Python。CATIA 功能需要已经安装并启动 CATIA V5。

升级时关闭旧版，替换 EXE 并保留现有 JSON 配置文件。生成几何体后自行确认并另存 CATPart / CATProduct；软件不会自动保存覆盖源 3DXML。

同时提供 `.sha256` 校验文件，源码可从对应标签下载。源码不包含现场模型、点位数据或本地配置。

## 验证与限制

- 82 项本地回归测试通过。
- 实际 3DXML Product 下生成 108 个整球面与 20 个正方体，中心坐标抽检通过；圆锥在临时 CATPart 中验证体积与重心；另验证取消后原组件名单保持不变。
- 发布 EXE 执行隔离启动检查。
- 3DXML 解析仅覆盖已验证的 V5_CFV3 结构及部分编码，未完全解码网格保留为候选。默认 2T 不代表源网格已经完成球面拟合；不同 CATIA 版本、文件编码和许可仍需现场验收。
